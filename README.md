# SPORT EDGE AI v0.5 — iPhone + HRB

Incluye seis deportes, modelos exploratorios NBA (normal) y NFL (Poisson) con parámetros manuales,
y Best Parlay 2–20, que compara alternativas y evita dos selecciones del mismo partido.

IMPORTANTE: no hay modelos entrenados, probabilidades calibradas ni cuotas HRB en vivo.
El optimizador usa probabilidades manuales e independencia hipotética; no garantiza ganancias.
No coloca apuestas. El registro CSV puede perderse en el servidor gratuito.

## Actualizar desde iPhone
1. Descomprime este ZIP desde Archivos.
2. En GitHub, abre tu repositorio y sustituye `app.py` por el de este paquete.
3. Confirma en la rama `main`; Streamlit redeplegará automáticamente.
4. Comprueba las pestañas NBA / NFL Models y Best Parlay 2–20.
`requirements.txt` no cambia respecto a v0.4.
